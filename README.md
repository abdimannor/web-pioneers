# Web Pioneers

A multi-page static website profiling three figures behind the modern internet: Tim Berners-Lee, Vint Cerf, and Google.

## Pages

- **Tim Berners-Lee** — inventor of the World Wide Web
- **Vint Cerf** — co-creator of TCP/IP and one of the founding architects of the internet
- **Google** — the search engine that shaped how the web is navigated
