# Web Pioneers

A small editorial site profiling figures and ideas behind the modern internet: Tim Berners-Lee, Vint Cerf, and Google.

## Live Demo

[abdimannor.github.io/web-pioneers](https://abdimannor.github.io/web-pioneers/)

## Pages

- **Home**: overview of the project
- **Tim Berners-Lee**: inventor of the World Wide Web
- **Vint Cerf**: co-creator of TCP/IP and one of the founding architects of the internet
- **Google**: the search engine that changed how people navigate the web
