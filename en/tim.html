The web

Tim Berners-Lee

Tim Berners-Lee made the internet more useful by joining hypertext, addresses, browser, web server and open standards into one coherent system.

What mattered was not only that information could be published. It could get an address, be linked onward and be read with the same basic rules no matter who built the page.

Read more about Tim Berners-Lee (Swedish Wikipedia)

Why he matters

He made information linkable on a global scale.

Before the web, the internet already existed as technical infrastructure. Berners-Lee's contribution was to give information a common form: documents could get addresses, link to each other and be shown in a browser.

That is why the web did not become a single app or service. It became a standardised environment where many players could publish, read and build further without having to belong to the same closed system.

1955

Born in London

Timothy John Berners-Lee was born on 8 June 1955 in London.1

1976

Physics at Oxford

He took a degree in physics at The Queen's College, Oxford, before moving on to programming and systems work.1

1980

Enquire at CERN

At CERN he built Enquire, an early system for connecting information through relationships.2, 1

1989

The WWW proposal

He presented the idea of a global hypertext project that developed into the World Wide Web.2

1990-1991

The first website

The first website was created at CERN in 1990. The following year the web became available to more users.3, 4

1994

W3C

He founded the World Wide Web Consortium to keep developing open web standards.5, 3

Building blocks

The web worked because several simple ideas fitted together.

HTML

Documents got structure: headings, text, links and content could be presented in a predictable way.

HTTP

Browsers and servers got a shared way to request and send documents over the network.

URL

Every resource could get its own address, which made links and navigation possible on a large scale.

Open standards

The web could spread because it did not have to be owned by a single player or locked to a single program.

Glossary

Technical terms on this page

Hypertext
Text with links to other texts, so that the reader can jump between documents instead of reading in a fixed order.
HTML
HyperText Markup Language. The markup language that gives a web page its structure: headings, paragraphs, images and links.
HTTP
Hypertext Transfer Protocol. The rules for how a browser requests a resource and how a web server sends it back.
URL
Uniform Resource Locator. The address of a resource on the web, for example https://www.w3.org/.
