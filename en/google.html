Searchability

Google

Google changed the web by making search the everyday starting point: a path from question to relevant page when the web became too big to survey by hand.

Its early strength lay in reading links as signals. A page was important not only because it contained the right words, but also because other pages pointed to it.

Read more about Google (Swedish Wikipedia)

Why Google matters

Search made the size of the web manageable.

As websites multiplied, it was not enough for the web to be open and linked. People needed to be able to find the right page without already knowing the address.

Google became important because search did not just present a list of hits. It became a sorting system for attention, credibility and everyday navigation.

1998

Founded

Google was started by Larry Page and Sergey Brin after work on how links could be used to rank web pages.1, 2

PageRank

Links as a signal

The early search model valued not only the words on the page, but also how other pages linked to it.2

Index

The web is gathered

The search engine built an index that made large amounts of web material quickly searchable.2

Relevance

Results in order

The key was not to find everything, but to show the most useful results first.

Everyday

Search as a habit

Google made web search a common first step whenever someone wanted to know, buy, compare or understand something.

Question

Power over visibility

When search becomes infrastructure, ranking affects which pages, voices and organisations are actually seen.

Building blocks

Search is both technology and selection.

Crawling

Automated systems follow links and discover pages that can be added to the index.

Indexing

The content of the pages is organised so that queries can quickly be matched against possible answers.

Ranking

Results are sorted by signals such as relevance, links, context and usefulness.

Trust

Search engines shape how people judge what seems relevant, visible and legitimate.
