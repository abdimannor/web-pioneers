Internetprotokoll

Vint Cerf

Vint Cerf var med och formade TCP/IP, protokollfamiljen som gjorde det möjligt för olika nätverk att kopplas ihop utan att bli ett enda centralt system.1, 2

Hans betydelse ligger i arkitekturen: internet skulle inte vara en plats, en dator eller ett företag, utan ett sätt för många självständiga nät att förstå varandra.

Fördjupa dig om Vint Cerf

Varför han spelar roll

Han hjälpte internet att växa utan att bli centralstyrt.

Vint Cerfs arbete kretsade kring ett grundproblem: hur får man skilda nätverk, byggda med olika teknik och för olika syften, att kommunicera på ett pålitligt sätt?

Svaret blev inte att alla skulle använda samma hårdvara eller samma lokala nät. I stället behövdes gemensamma regler för hur information delas upp, adresseras, skickas och sätts ihop igen. Det är en viktig anledning till att internet kunde växa organiskt.

1943

Född i USA

Vinton Gray Cerf föddes i Connecticut och blev senare en central person bakom internets tekniska grund.3

1970-tal

Arbetet med Bob Kahn

Cerf och Kahn utvecklade idéerna bakom TCP/IP, grunden för internets kommunikationsmodell.1, 4

1983

TCP/IP blir standard

När ARPANET gick över till TCP/IP blev modellen ett praktiskt fundament för det internet som sedan växte fram.5, 4

1990-tal

Internet blir publikt

Protokollens öppna karaktär gjorde att fler nät, universitet, företag och användare kunde kopplas in.4

2000-tal

Fortsatt internetarbete

Cerf fortsatte arbeta med internets utveckling, standarder, tillgänglighet och långsiktiga ansvar.2

Princip

Nätverk av nätverk

Hans arbete visar varför internet fungerar bäst när olika system kan mötas genom öppna regler.

Byggstenar

Internet behövde regler för rörelse, inte bara anslutningar.

TCP

Delar upp data, håller ordning på leveransen och gör kommunikationen mer tillförlitlig.

IP

Ger paket adresser och gör det möjligt för dem att hitta vägar mellan olika nätverk.

Paketförmedling

Information skickas i mindre delar som kan ta olika vägar och ändå sättas ihop igen.

Öppen sammankoppling

Nya nät kan ansluta utan att hela systemet behöver byggas om från grunden.

Prova själv

Ett meddelande, många vägar.

Meddelandet delas upp i numrerade paket. Varje paket skickas för sig, och routrarna kan leda dem längs olika vägar. Därför kan de komma fram i fel ordning. Hos mottagaren använder TCP numren för att sätta ihop meddelandet i rätt ordning. (I verkligheten räknar TCP:s sekvensnummer byte, inte hela paket.)

    Ordlista

    Tekniska begrepp på sidan

    TCP/IP
    Protokollfamiljen som internet bygger på. IP ger datapaket adresser och leder dem mellan nätverk, TCP håller ordning på leveransen så att data kommer fram komplett och i rätt ordning.
    Paketförmedling
    Data delas upp i små paket som skickas var för sig, kan ta olika vägar genom nätet och sätts ihop igen hos mottagaren.
